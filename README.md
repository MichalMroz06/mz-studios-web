# MZ Studios - Official Web Platform

Nowoczesna, wysokowydajna platforma internetowa stworzona dla studia gier wideo oraz software house'u. Projekt ma na celu prezentację portfolio gier, aplikacji, wpisów na blogu/devlogach oraz umożliwienie kontaktu z klientami i inwestorami.

---

## Stos Technologiczny (Tech Stack)

- **Framework:** [Next.js 15](https://nextjs.org/) (App Router)
- **Biblioteka UI:** [React 18](https://react.dev/) / [Tailwind CSS](https://tailwindcss.com/)
- **Język:** [TypeScript](https://www.typescriptlang.org/)
- **Komponenty / Ikony:** [Material-UI (MUI)](https://mui.com/)

---

## Kluczowe Funkcjonalności

- **Game & Portfolio Showcase:** Prezentacja wydanych i nadchodzących projektów gier oraz aplikacji (m.in. opisy, screenshoty, devlogi, linki do itch.io).
- **Devlog & News Hub:** System artykułów i aktualizacji tworzonych przez zespół.
- **Formularz Kontaktowy & Lead Generation:** Integracja z backendem/SMTP do obsługi zapytań ofertowych i wsparcia.
- **Fully Responsive & Dark Theme:** Interfejs zaprojektowany z myślą o urządzeniach mobilnych oraz mrocznym, gamedevowym klimacie.

## Uruchomienie Projektu Lokalnie

### Wymagania Wstępne

Upewnij się, że masz zainstalowane:
- **Node.js:** `>= 18.x`
- **npm** / **pnpm** / **yarn**

### Krok 1: Klonowanie Repozytorium

```bash
git clone https://github.com/MichalMroz06/mz-studios-web.git
cd mz-studios-web
```

### Krok 2: Instalacja Zależności

```bash
npm install
```

### Krok 3: Uruchomienie Serwera Deweloperskiego

```bash
npm run dev
```
